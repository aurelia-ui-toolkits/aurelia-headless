Aurelia Headless UI

Accessible, composable primitives for Aurelia 2 applications. Start with a ready-made theme, swap to compact with one import, or replace the CSS with your own design.

Swap themes

Themes are plain CSS packages. The headless components stay the same; swap the package import to change the visual system. Try the Default/Compact segmented control in the top bar to reload this demo with the other theme package.

Build your own theme

Use the shipped theme as a starting point or import individual files. Keep theme.css for tokens, then replace component theme files as your design system grows.

Update default colours

Override the default theme by loading your CSS after @aurelia-ui-toolkits/headless-tailwind. Change the tokens first; component themes read from these variables.

For tone colours, override semantic tokens such as --color-success-bg, --color-warning-text, and --color-danger-border.
