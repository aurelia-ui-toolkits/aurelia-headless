Aurelia Headless UI

Accessible, composable primitives for Aurelia 2 applications. Use the default theme to get moving, then replace it with your own CSS when you need a personalised design.

Browse components GitHub 
npm install aurelia-headless aurelia-headless-tailwind
 
import Aurelia from 'aurelia';
import { AureliaHeadlessConfiguration } from 'aurelia-headless';
import 'aurelia-headless-tailwind';

Aurelia
  .register(AureliaHeadlessConfiguration)
  .app(MyApp)
  .start();

aurelia-headless-tailwind is a sensible default theme, not a requirement. It is intended to be replaced by app-owned CSS for branded or product-specific themes.

// Default theme for prototypes and quick starts
import 'aurelia-headless-tailwind';

// Later, replace it with your own CSS
import './styles/my-product-theme.css';
