Aurelia Headless UI

Accessible, composable primitives for Aurelia 2 applications. Bring your own styling, keep the behavior.

Browse components GitHub 
npm install aurelia-headless
 
import Aurelia from 'aurelia';
import { AureliaHeadlessConfiguration } from 'aurelia-headless';

Aurelia
  .register(AureliaHeadlessConfiguration)
  .app(MyApp)
  .start();
