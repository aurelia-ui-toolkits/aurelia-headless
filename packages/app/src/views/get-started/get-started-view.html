Aurelia Headless UI

Accessible, composable primitives for Aurelia 2 applications. Use the default theme to get moving, then replace it with your own CSS when you need a personalised design.

Browse components GitHub 
npm install aurelia-headless aurelia-headless-tailwind
 
import Aurelia from 'aurelia';
import { AureliaHeadlessConfiguration } from 'aurelia-headless';
import 'aurelia-headless-tailwind';

Aurelia
  .register(AureliaHeadlessConfiguration)
  .app(MyApp)
  .start();

aurelia-headless-tailwind is a sensible default theme, not a requirement. It is intended to be replaced by app-owned CSS for branded or product-specific themes.

// Default theme for prototypes and quick starts
import 'aurelia-headless-tailwind';

// Later, replace it with your own CSS
import './styles/my-product-theme.css';

Override the default theme by loading your CSS after aurelia-headless-tailwind. Change the tokens first; component themes read from these variables.

import 'aurelia-headless-tailwind';
import './styles/brand-theme.css';
/* brand-theme.css */
:root {
  --color-primary-600: #7c3aed;
  --color-primary-700: #6d28d9;
  --color-primary-800: #5b21b6;
  --color-ring: #c4b5fd;

  --color-card: #ffffff;
  --color-card-muted: #f6f2ff;
  --color-card-border: #ddd6fe;
}

:root[data-theme="dark"] {
  --color-primary-600: #a78bfa;
  --color-primary-700: #c4b5fd;
  --color-primary-800: #ddd6fe;
  --color-ring: #8b5cf6;

  --color-card: #171123;
  --color-card-muted: #211834;
  --color-card-border: #4c1d95;
}

For tone colours, override semantic tokens such as --color-success-bg, --color-warning-text, and --color-danger-border.
